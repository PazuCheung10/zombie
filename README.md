# 守望實驗室

純前端、俯視 2D 的抽象演化模擬。按「開始訓練」，觀看守衛學習保護平民，以及會逐步進化的喪屍。介面採用繁體中文，主要設定收進可展開的進階面板。

## 啟動與驗證

需要 Python 3（本機靜態伺服器）、Node.js 22（測試與打包）。沒有外部執行依賴。

```sh
npm start
# 開啟 http://127.0.0.1:5173/
npm test
npm run build
```

`dist/` 是可部署到任何靜態網站服務的完整網站。所有模組使用相對路徑，可放在 GitHub Pages 的專案子路徑。

## 模型儲存

訓練由瀏覽器的 Web Worker 執行，沒有訓練後端，也沒有使用 TensorFlow 等機器學習套件。模型是 JavaScript 數字陣列，由自行實作的遺傳演算法選拔、交叉和突變。

- `localStorage` 自動保存最新完整訓練狀態：雙方族群、模型、隨機數狀態、難度與待升級課程。
- 原生 `IndexedDB` 每代保存完整快照。預設比較清單顯示起點與每 500 代；進階設定可改成 100／50 代，或輸入已保存的確切代數。
- 「學習起點」永久保留開始時的守衛策略；全新實驗從未進化策略開始，不會自動載入預訓練模型。
- 從舊代數繼續會建立新分支，原分支留在瀏覽器。更改參數保留已學策略，重新建立候選族群並重新評分。
- JSON 備份包含最新完整狀態及最多 30 個比較快照（最初一個與最近的里程碑），不包含 IndexedDB 內每一代的完整歷史。
- 舊版 v1／v2 模型保留已學守衛權重及代數，在新規則下重新評估；v3 完整快照可精確接續。

儲存屬於目前瀏覽器及網址來源。更換電腦、瀏覽器、埠號或由 localhost 轉到 GitHub Pages，不會自動搬移模型，請使用下載／載入備份。清除網站資料會刪除記錄；儲存容量耗盡時介面會提示備份。關閉頁面後訓練停止。

## 世界與學習

- 1200 × 800 場地，每局依種子生成 4–7 個分散障礙物。左右比較使用同一地圖、敵人及難度。
- 建議設定：3 守衛、10 平民、28 起始喪屍、24 候選模型、每模型 3 局、20% 突變機率，畫面 3 倍速。
- 最長 55 秒。平民全滅或所有喪屍清除便立即結算；未出場的波次仍算威脅。清場後的安全生存時間直接補入分數，無須空等。
- 平民被感染後立即變色，一秒後開始以喪屍行動。大型喪屍有較高血量及不同速度；大型為紫色、衝刺型為橙色，衝刺時柔和閃動。
- 守衛只有視野及牆壁遮擋內的觀察，從前後位置估計速度與加速度，嘗試提前瞄準。子彈有飛行時間及碰撞，不是瞬間命中。守衛看不到隱藏血量、敵人網絡權重或真實速度，只能觀察大小、移動及目擊命中。
- 守衛以 20 個可演化的效用權重選擇射擊、補給、保護、退後、近戰與搜尋。守衛不是深層神經網絡；瞄準與局部避障仍有共用幾何機制，並非所有物理行為都由零學起。
- 喪屍使用 10 輸入 → 6 隱藏神經元 → 3 輸出的微型網絡，共 87 個權重。輸出控制目標偏好、油門與側向移動，可以停步。
- 守衛分數主要是平民存活數；喪屍分數主要是感染平民數，沒有預設擊殺守衛獎勵。
- 喪屍族群每 4 代演化一次；場景 GA 另外調整數量、速度、衝刺比例、平民分散程度與波次。新敵人／難度通過生存率門檻才會採用，並混入舊課程減少遺忘。

這是有界的可生存難度搜尋，不保證每次升級、每局必勝或無限變強。驗證種子參與選拔，介面的成績不是獨立的泛化能力證明。場地採簡單局部避障，並非完整路徑規劃。

## 測試範圍

`npm test` 驗證種子重現、視野遮擋、隨機障礙物、連續子彈碰撞、感染一秒延遲、提前結算、速度觀察、敵人網絡、舊檔遷移、完整雙族群續練、歷史分支、里程碑及難度更新後重新評分。

`npm run benchmark` 與 `npm run benchmark:curriculum` 可進行較長的實驗。`fixtures/legacy-gen47.json` 僅作遷移測試資料，不會載入公開網站。不同 JS 引擎不承諾浮點運算完全一致。

## 檔案

`sim.js` 管理物理與守衛策略；`zombie-policy.js` 定義敵人網絡；`evolution.js`／`challenge.js` 管理演化；`worker.js` 背景訓練；`persistence.js`／`history-db.js`／`timeline.js` 管理保存；`app.js`／`index.html`／`style.css` 呈現介面。
